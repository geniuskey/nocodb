# RowWeave backend

This package contains the RowWeave Community backend. Its package name remains
`nocodb` because workspace filters, deployment scripts, migrations, and
baseline consumers depend on that technical identifier.

Use the root commands in [`docs/BUILDING.md`](../../docs/BUILDING.md) instead of
installing this package independently. Compatibility policy is documented in
[`docs/COMPATIBILITY.md`](../../docs/COMPATIBILITY.md).
