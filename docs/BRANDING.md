# RowWeave branding

## Product identity

- Name: **RowWeave**
- Tagline: **Weave data into work.**
- Descriptor: **An independent AGPL no-code base platform compatible with the
  NocoDB 0.265.1 AGPL baseline.**

Use `RowWeave` for page titles, logos, screenshots, package descriptions,
container names, documentation, and community channels.

## Compatibility wording

Acceptable informational wording:

- “Compatible with the NocoDB 0.265.1 AGPL baseline.”
- “Imports baseline NocoDB-format metadata.”
- “Independent continuation of the final modern AGPL source commit.”

Do not call RowWeave a current NocoDB edition, promise compatibility with later
releases, use upstream logos, or imply endorsement.

Internal compatibility identifiers listed in `COMPATIBILITY.md` are exempt
from product-name replacement. In particular, “Import from NocoDB” is the name
of a compatibility operation and should not be relabelled “Import from
RowWeave” unless the operation actually imports RowWeave exports.

## Logo

The RowWeave mark uses independently drawn interwoven rows:

- `packages/nc-gui/assets/img/brand/rowweave-mark.svg`
- `packages/nc-gui/assets/img/brand/rowweave-wordmark.svg`
- `packages/nc-gui/public/favicon.svg`

Do not modify an upstream NocoDB logo to create RowWeave artwork. New variants
should be derived from these RowWeave SVG sources.
